# Script Guidance

This file tells the script-writing stage how to talk about the researched material.

## Voice and Framing
- use a concise, practical, audio-native voice
- expand acronyms naturally when useful
- avoid reading tables, repeated labels, or obvious bullet structure out loud

## Episode Defaults
- overview episodes should build mental model and context
- deep dives should assume the overview already covered the basics
- deep dives should focus on mechanics, tradeoffs, failure modes, and practical engineering understanding
- avoid repeating the same points across overview and deep dive unless repetition is necessary for clarity
